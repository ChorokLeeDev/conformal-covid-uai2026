%------------------------------------------------------------------------------
% KEY INSIGHT
%------------------------------------------------------------------------------
\posterbox{Key Insight}{%
\fontsize{26}{33}\selectfont

Models with \textbf{concentrated feature reliance} are at risk:

\vspace{0.6em}
\begin{itemize}
    \item[\color{uaiblue}$\bullet$] Single feature drift $\Rightarrow$ large impact
    \item[\color{uaiblue}$\bullet$] Less redundancy across features
    \item[\color{uaiblue}$\bullet$] APS scores inflate after shift
\end{itemize}

\vspace{0.8em}
\begin{center}
\fcolorbox{uaiblue}{uailight}{\parbox{0.72\linewidth}{\centering
\vspace{0.22em}
{\fontsize{27}{33}\selectfont\bfseries High concentration}\\[0.12em]
{\fontsize{23}{29}\selectfont $\Downarrow$}\\[0.12em]
{\fontsize{27}{33}\selectfont\bfseries\color{uaiblue} Risk flag}
\vspace{0.22em}
}}
\end{center}
}

%------------------------------------------------------------------------------
% SHAP CONCENTRATION METHOD
%------------------------------------------------------------------------------
\posterbox{Mechanism \& Theory}{%
\fontsize{25}{31}\selectfont

\textbf{Top-1 concentration: share of mean absolute SHAP importance}
\vspace{0.22em}
\begin{center}
\fcolorbox{uaiblue}{uailight}{\parbox{0.92\linewidth}{\centering
\vspace{0.32em}
{\fontsize{34}{42}\selectfont $\displaystyle C = \frac{\max_j \mathbb{E}|\phi_j|}{\sum_{j=1}^{p} \mathbb{E}|\phi_j|}$}
\vspace{0.32em}
}}
\end{center}

\vspace{0.22em}
\begin{center}
\fcolorbox{uaiblue}{uailight}{\parbox{0.95\linewidth}{\centering
\vspace{0.24em}
{\fontsize{19}{23}\selectfont\bfseries\color{uaiblue}Idealized theorem: concentration amplifies APS score inflation}\\[0.15em]
{\fontsize{18}{22}\selectfont
$\displaystyle
\mathbb{E}[s_{\mathrm{test}}] \geq C\bigl(1-(K-1)\epsilon\bigr) + (1-C)\bigl(1-(K-1)\bar h\bigr)$}\\[0.45em]
\begin{minipage}{0.92\linewidth}
{\fontsize{18}{22}\selectfont\raggedright
If the dominant shifted feature gives weaker true-class support ($\epsilon<\bar h$), larger $C$ puts more weight on that damaged signal. APS test scores rise while the CP cutoff stays fixed, so coverage drops.\par
}
\end{minipage}
\vspace{0.24em}
}}
\end{center}

\vspace{0.45em}
\begin{center}
\makebox[\linewidth][c]{\includegraphics[width=0.99\linewidth]{../figures/figure3_feature_importance.png}}
\end{center}
{\fontsize{20}{24}\selectfont\itshape Fig. 2: Catastrophic tasks concentrate SHAP mass on one shifted feature; robust/protected tasks keep reliance distributed or stable.\par}
\vspace{0.18em}
{\fontsize{18}{22}\selectfont
\setlength{\tabcolsep}{0.3em}
\begin{tabular}{@{}>{\raggedright\arraybackslash}p{0.49\linewidth}>{\raggedright\arraybackslash}p{0.49\linewidth}@{}}
\textbf{A. Failure:} SHAP mass jumps to one feature. &
\textbf{B. Robust:} importance stays distributed. \\
\textbf{C. Ratio:} failing task has a top-feature spike. &
\textbf{D. Stability:} robust tasks keep feature order. \\
\end{tabular}\par
}
\vspace{0.2em}
\begin{center}
\fcolorbox{uaiblue}{uailight}{\parbox{0.94\linewidth}{\centering
\vspace{0.18em}
{\fontsize{21}{25}\selectfont\bfseries\color{uaiblue}Mechanism: high-\(C\) GBMs can create a single point of failure.}\\[0.12em]
{\fontsize{18}{22}\selectfont The claim is directional: stable/protective top features can be exceptions.}
\vspace{0.18em}
}}
\end{center}
}

%------------------------------------------------------------------------------
% CONCLUSIONS
%------------------------------------------------------------------------------
\posterbox{Conclusions \& Future Work}{%
\fontsize{25}{31}\selectfont

\textbf{\color{uaiblue}Takeaways:}
\begin{itemize}
    \setlength\itemsep{0.12em}
    \item Top-1 SHAP concentration predicts APS CP coverage loss \textbf{in GBMs}: $\rho=0.853$ ($p<0.001$)
    \item The 40\pct{} cutoff is exploratory: \textbf{91.7\pct} label agreement across 12 checks (11/12)
\end{itemize}

\vspace{0.35em}
\textbf{\color{uaiblue}Future Directions:}
\begin{itemize}
    \setlength\itemsep{0.12em}
    \item \textbf{Prospective validation:} test the cutoff on new domains
    \item \textbf{Protective factors:} detect stable top features that prevent failure
    \item \textbf{Neural diagnostics:} gradient-based explanations for MLPs
    \item \textbf{Mitigation:} reduce concentration via features, dropout, ensembles
\end{itemize}
}
